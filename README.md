# Skilledit

Skilledit is a video-editing skill and Remotion workspace. The experimental browser-based slideshow MVP and its Render instructions are in [`skill autoedit/`](./skill%20autoedit/README.md).

For a Render test deployment, set the service root directory to `skill autoedit`, use the Docker runtime, and set the Dockerfile path to `remotion/Dockerfile`. The web MVP requires an `APP_PASSWORD` environment variable in production.
